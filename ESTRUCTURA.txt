REGLAS DE ORO
═══════════════════════════════════════════════════════════════

1. Page Resources son "Append-Only"
   ✓ Agregar nuevos locators al final
   ✗ NUNCA eliminar ni modificar locators existentes

2. Prioridad de Locators
   1º id:elemento
   2º name:elemento
   3º css:.clase
   4º xpath://ruta (último recurso)

3. Separación de Responsabilidades
   • Test Cases (.robot)    → Lógica de negocio (Given/When/Then)
   • Keywords (resource)    → Acciones reutilizables
   • Page Resources         → Locators y keywords de página

4. Tags Obligatorios
   • PruebaGeneradaIA (en todos los Test Cases)
   • Tags adicionales: Funcional, Ofertas, AmigoPaguitos, etc.

5. Nomenclatura
   • Variables locators:    ${MAYUSCULAS_CON_GUION}
   • Keywords:             En Español Con Mayúsculas Iniciales
   • Archivos Test:        TC_###_Nombre_Descriptivo.robot
   • Archivos Page:        NombreModuloPage.resource


FLUJO DE EJECUCIÓN
═══════════════════════════════════════════════════════════════

Test Case (.robot)
    ↓
Llama Keywords (keywords.resource)
    ↓
Llama Keywords de Página (pages/*.resource)
    ↓
Usa Locators (Variables en pages/*.resource)
    ↓
Interactúa con SeleniumLibrary
    ↓
Ejecuta en Navegador


COMANDOS ÚTILES
═══════════════════════════════════════════════════════════════

# Instalar dependencias
pip3 install -r requirements.txt

# Ejecutar todos los tests
./run_tests.sh all
robot -d reports tests/

# Ejecutar un test específico
./run_tests.sh tc032
robot -d reports tests/TC_032_Validacion_Oferta_Primaria_Amigo_Paguitos.robot

# Ejecutar por tags
./run_tests.sh ofertas
robot -d reports -i PruebaGeneradaIA tests/
robot -d reports -i Ofertas tests/
robot -d reports -i AmigoPaguitos tests/

# Validar sintaxis (dry run)
./run_tests.sh dryrun
robot --dryrun -d reports tests/

# Ver ayuda del script
./run_tests.sh help
